# 云宿充 · C端充电小程序交互原型 2.1

面向 C 端车主的高保真交互原型，覆盖找站、扫码、实时充电、暂停/恢复、结束结算与个人服务。

## 功能覆盖

- **扫码充电**：扫桩码 → 确认枪号 → 实时充电 → 暂停/恢复 → 结束确认 → 结算明细
- **首页服务**：场站搜索与历史记录、收藏场站、最近充电、余额充值、优惠卡券
- **地图与场站**：价格/空闲数地图气泡、地图/列表切换、快捷与组合筛选、场站设施、8 段全天费率与终端状态
- **活动中心**：活动列表、独立活动详情、活动规则、适用场站与参与入口
- **余额充值**：充值套餐选择、支付确认、到账与余额实时更新
- **会员中心**：未开通和已开通两种状态，仅提供会员场站服务费折扣
- **优惠卡券**：全部、快过期、已失效卡券，支持满减券、折扣券、扫码领券与兑换码
- **我的**：余额、卡券、订单、车辆、发票、收藏、最近充电、客服与设置

## 交互说明

- 首页活动卡支持触摸横滑、左右切换和分页指示。
- 首页“为你推荐”标题在场站列表上滑时吸顶，场站卡片正常随页面滚动。
- 场站详情采用“场站概况 / 充电价格 / 终端列表”分区，避免信息全部纵向堆叠。
- 桌面浏览时可通过左侧导航直达各页面；移动端自动使用全屏安全区布局。

## 本地运行

纯静态单文件，任选一种方式：

```bash
# Python
python -m http.server 8080
# 或 Node
npx serve .
```

浏览器访问 http://localhost:8080 即可（桌面端自动呈现手机壳 + 页面直达侧栏；窄屏下全屏呈现）。
