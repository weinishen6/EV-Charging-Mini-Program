# 云宿充 · C端充电小程序 交互原型

面向 C 端用户（车主）的充电小程序高保真交互原型，覆盖扫码充电完整流程与运营配置展示。

## 功能覆盖

- **扫码充电**：扫桩码 → 确认枪号 → 实时充电页（电量/功率/时长/金额实时累加，分时电价计费）→ 结算明细
- **地图与场站**：首页地图图钉（空闲数量着色）、场站列表（快充/慢充/低价/距离筛选）、场站详情（分时电价、枪位状态、场站活动）
- **活动中心**：新用户立减、充值满赠、邀请有礼、超充服务费折扣、会员日等活动详情与规则
- **余额充值**：充值套餐档位（后台配置）、微信支付模拟、到账与余额实时更新
- **会员中心**：等级体系（普通/黄金/白金/钻石）、成长值进度、折扣与卡券权益、会员码
- **我的**：钱包、卡券、订单、车辆、发票、客服等入口

## 与运营后台的对应关系

原型数据集中在 `index.html` 顶部的 `SERVER_CONFIG` 对象中，模拟以下后台模块下发，前端一律按配置渲染：

| 后台模块 | 小程序展示 |
| --- | --- |
| 场站管理 | 地图图钉、场站列表、详情、枪状态 |
| 收费配置 | 分时电价（尖峰平谷）+ 服务费 |
| 充值套餐 | 钱包页套餐档位与赠送金额 |
| 活动管理 | 首页 Banner、活动中心、场站活动标签 |
| 会员等级 | 会员卡、折扣权益、成长值 |
| 卡券营销 | 优惠券列表、下单抵扣 |

## 本地运行

纯静态单文件，任选一种方式：

```bash
# Python
python -m http.server 8080
# 或 Node
npx serve .
```

浏览器访问 http://localhost:8080 即可（桌面端自动呈现手机壳 + 页面直达侧栏；窄屏下全屏呈现）。
